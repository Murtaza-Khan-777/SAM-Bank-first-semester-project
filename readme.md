# SAM Bank Management System

A desktop banking application built with Python (Tkinter) and SQLite. This application allows users to simulate basic banking operations including account creation, money transfers, and transaction history tracking.

## 🚀 Features

* **User Authentication**: Secure Login and Sign-up system with email validation.
* **Dashboard**: Real-time view of account balance and welcome message.
* **Money Transfer**: Send money to other users using their unique Account ID.
* **Transaction History**: View a log of incoming and outgoing transfers.
* **Rewards System**: Play a Tic-Tac-Toe mini-game to earn extra cash rewards! 🎮

## 🛠️ Tech Stack

* **Language**: Python 3.x
* **GUI Framework**: Tkinter (Standard Python library)
* **Database**: SQLite3
* **Images**: Custom PNG assets
